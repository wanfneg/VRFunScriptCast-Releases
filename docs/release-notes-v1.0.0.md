# VRFunScriptCast v1.0.0

**原生 OpenXR 正式版 · 首个单包版本 · 2026-10-17**

这是 VRFunScriptCast 从 Unity 迁移到原生 Android + OpenXR 后的第一个正式版。
从本版起，**不再区分 Meta / Pico 两个安装包**，只发布一个 `arm64-v8a` APK。

## 重要变化

- **彻底移除 Unity**：原生 OpenXR 渲染 + Kotlin/Compose 真窗口面板 + ExoPlayer 解码。
- **单包发布**：`VRFunScriptCast-1.0.0-arm64.apk`；不再提供 `-Meta` / `-Pico` 分包。
- **签名变化**：与旧 Unity 版、测试 debug 版签名不同，**覆盖安装会失败，请先卸载旧版**。
- **脚本加载优先级**：本地视频 `同目录 → 本地脚本文件夹 → 远程脚本文件夹`；
  网络视频 `网络同目录 → 本地脚本文件夹 → 远程脚本文件夹`。网络同目录优先于本地索引。
- **播放页「浏览文件」**：三来源栏（媒体库 / 本地文件 / 网络源）+ 当前文件夹 + 3 列卡片，与主页状态双向同步。
- **脚本健壮性**：坏 JSON / 空 `.funscript` 不再触发约 30 秒无效重试，自动回退空脚本并记录警告。
- **UI**：热力图进度条、四个弹窗（视频透传 / 联动控制 / 预设模式 / 浏览文件）、MR 抠像与 Alpha 通道。

## 安装

1. 下载 `VRFunScriptCast-1.0.0-arm64.apk`。
2. 如已安装旧 Unity 版或测试版，先在头显里**卸载**。
3. SideQuest 侧载，或：

```powershell
adb install -r VRFunScriptCast-1.0.0-arm64.apk
```

首次启动授予存储权限（本地视频）与蓝牙权限（设备）。

## 已知限制

- 视频透传的「自动识别」按钮已预留，但帧回读通道未接线，当前版本需手动调颜色容差 / 边缘羽化。
- PICO 兼容代码保留，但本版真机验收以 **Meta Quest 3** 为准。
- AI 字幕需要 PC 端字幕服务（默认端口 8756），不是头显本地离线识别。
- 空间音频尚未实现；当前为普通立体声。
