# VRFunScriptCast v1.5.0 更新说明

## 新增

- **连播**：视频播完自动播同目录下一个（设置 → 跳过面板可关，默认开）。
- **上一集 / 下一集**：播放页 ±10s 两侧新增两个按钮，无相邻视频时置灰不可点击。
- **倍速**：播放器控件顶部新增倍速按钮，四档循环（1.0× / 1.25× / 1.5× / 2.0×），每次起播回到 1.0×。
- **失败重试**：播放失败横幅加「重试」，原样重放上次请求，不用退出重进。
- **手动加载或切换脚本**：未自动加载到匹配脚本时可手动浏览加载脚本。
- **浏览位置记忆**：文件浏览器按目录记住滚动位置；播放页浏览器高亮当前视频。

## 改进

- **改善面板滚动流畅度**
- **改善UI交互反馈**

## 修复

- **VR 视角缩放画面畸变问题**
- **播放页浏览弹窗滚动失效问题**
