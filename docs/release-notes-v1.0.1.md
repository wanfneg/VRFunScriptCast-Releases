# VRFunScriptCast v1.0.1

**MR 自动识别完善 · 2026-10-19**

## 本版重点

- **视频透传「自动识别」真正可用**：从当前视频帧取背景主色，绿幕/蓝幕自动切换色相键，灰底/纯色背景自动切换纯色键；识别结果会保存，换片/重启不丢。
- **取样更稳**：优先取画面外圈（主体在中心时不会被主体色带偏），使用圆形色相统计与自适应容差；背景噪声大时自动放宽，干净绿幕自动收紧。
- **失败原因可诊断**：没有视频帧、GL 资源失败、`glReadPixels` 失败会直接显示原因，不再统一等超时。
- **修复旧问题**：
  - 旧回读读场景 FBO，Flat 模式会把天空盒/窗口外背景采进“画面边缘”，导致键色识别错误；
  - 识别失败后按钮可能永久“正忙”；
  - RGBA/ARGB 通道顺序错误会让蓝幕被识别成红幕。
- **兼容升级**：1.0.0 → 1.0.1 同签名，可直接覆盖安装，保留应用内数据。

## 安装

1. 下载 `VRFunScriptCast-1.0.1-arm64.apk`。
2. 1.0.0 可直接覆盖升级；旧 Unity 版 / 测试 debug 版签名不同，需要先卸载。
3. SideQuest 侧载，或：

```powershell
adb install -r VRFunScriptCast-1.0.1-arm64.apk
```

首次启动授予存储权限（本地视频）与蓝牙权限（设备）。

## 真机验证

- Meta Quest 3：绿幕测试片识别为绿键（120°）；灰底测试片识别为纯色键 `#808080` / 12% 容差；灰底识别后切换到绿幕片，持久化键色在起播时自动生效。
- 识别结果已复位为 MR 关闭 / 默认容差，测试视频已清理。

## 已知限制

- 自动识别取的是**当前视频帧**；主体颜色接近背景、或背景有花纹/渐变时，结果只作为起点，建议用「蒙版预览」核对后再微调。
- PICO 兼容代码保留，但本版真机验收以 **Meta Quest 3** 为准。
- AI 字幕需要 PC 端字幕服务（默认端口 8756）。
- 空间音频尚未实现；当前为普通立体声。
