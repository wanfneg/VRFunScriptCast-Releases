# VRFunScriptCast v1.5.1 更新说明

## 新增

- **连播**：视频播完自动播同目录下一个（设置 → 跳过面板可关，默认开）。
- **上一集 / 下一集**：播放页 ±10s 两侧新增两个按钮，无相邻视频时置灰不可点击。
- **倍速**：播放器控件顶部新增倍速按钮，四档循环（1.0× / 1.25× / 1.5× / 2.0×），每次起播回到 1.0×。
- **失败重试**：播放失败横幅加「重试」，原样重放上次请求，不用退出重进。
- **手动加载或切换脚本**：未自动加载到匹配脚本时可手动浏览加载脚本。
- **浏览位置记忆**：文件浏览器按目录记住滚动位置；播放页浏览器高亮当前视频。

## 激活说明

- 本次更新加入了**激活码验证**，用于解锁**设备联动**功能（BLE / TCode / Intiface）。播放、文件浏览、网络源等其余功能不受影响，仍然免费。
- **抚物（ServeU）用户免费**：已购买抚物设备的用户无需购买许可证，请联系作者本人 QQ `2831691505` 免费激活。
- 其它设备用户可在「设置 → 激活」粘贴订单号 / 交易号后点「领取」自动激活。

## 安装说明

- 单包 `arm64-v8a`，`versionCode 10501 / versionName 1.5.1`，可从 1.5.0 直接覆盖升级。
